# VAIDYA AI — Public evaluation source

Tamil–English ASR (Sarvam Saaras V4), LangGraph, and AWS Bedrock extraction demonstration.

**Not validated for clinical use. Do not upload identifiable patient recordings or medical documents.**

Use private `.env` credentials only; never commit secrets, recordings, generated reports, or databases.

This public repository will contain source, configuration templates, tests, and development documentation. Some tests are skipped without external services and the paid cloud APIs require separate live verification.
